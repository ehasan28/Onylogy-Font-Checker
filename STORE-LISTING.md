WHAT IT DOES

Hover any text on a web page to see its exact font: family, weight, size,
line height, letter spacing, color, and text transform — all in a frosted-
glass card that follows your cursor. Click any text to pin a full data
card right next to that element. Pin as many as you like. Scroll the page
and the pinned cards scroll with the content where you placed them.

Open the popup to:
  •  Identify what Google Font, Adobe Font, or self-hosted font a site uses
  •  Scan the entire page's typography hierarchy in one click (H1–H6,

  •  Detect the modular scale ratio behind the type sizes

  •  Run eight readability checks against WCAG and the established
     typographic baselines
  •  Export the captured system to CSS variables, Tailwind config, SCSS,
     JSON, WordPress Kadence Global Typography, or responsive clamp()

## Permission justifications

Chrome's Manifest V3 review process asks you to justify every requested
permission. Paste these verbatim into the corresponding fields on the
"Privacy practices" tab of the Developer Dashboard.

### Single purpose

```
Onylogy Font Checker is a typography inspection tool. Its single purpose
is to identify fonts and CSS typography on the user's currently focused
tab, surface that information in a popup and an on-page overlay, and
export the captured typography system as developer-ready design tokens
(CSS variables, Tailwind, SCSS, JSON, Kadence, and responsive clamp()).
```

### `activeTab` justification

```
activeTab is used to read the computed styles of text elements on the
tab the user is currently focused on, only when the user explicitly
invokes the extension by clicking the toolbar icon or pressing the
keyboard shortcut. This is the minimum permission needed to inspect
typography on the current page. The extension does not access any
other tabs or run in the background.
```

### `scripting` justification

```
scripting is used as a fallback to inject the content script into tabs
that were already open when the extension was first installed or
reloaded. Without this, those existing tabs would silently not work
until the user reloaded them. The script is injected only on user
action (clicking the toolbar icon or invoking the keyboard shortcut)
and only into the user's currently focused tab.
```

### `storage` justification

```
storage is used to save user preferences locally in
chrome.storage.local: theme (light/dark), default unit (px/rem/em),
default export format, the list of recently inspected font family
names (max 30), and the most recent hierarchy / accessibility scan
results so the popup doesn't have to re-scan every time it opens. No
data is transmitted off-device. No personal information is stored.
```

### Host permissions justification

```
No host permissions are requested. The extension uses content scripts
declared with the <all_urls> match pattern, which does not generate a
permissions warning at install time and only executes when the user
explicitly invokes the extension on a given tab.
```

### Remote code justification

```
The extension does not load or execute any remote code. The only
external network request that may occur is the browser's own font
loader fetching Google Fonts (Bricolage Grotesque, Montserrat,
JetBrains Mono) for the popup and on-page overlay's UI. This is a
standard browser font request, not extension code execution.
```
